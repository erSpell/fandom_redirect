# fandom_redirect

fandom_redirect redirects Fandom wiki pages to their matching Antifandom pages.

For example:

https://minecraft.fandom.com/wiki/Dirt
→ https://minecraft.antifandom.com/wiki/Dirt

Install it from the Mozilla Add-ons store:

https://addons.mozilla.org/en-US/firefox/addon/fandom-to-antifandom/
